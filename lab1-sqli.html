SQL Injection

登入系統把使用者輸入直接拼進 SQL 查詢字串，攻擊者可藉此繞過登入驗證，並進一步新增、竄改或刪除資料庫內容。

嚴重度 High   PORT 5000

漏洞原理

登入時伺服器組出的查詢語法如下，使用者輸入被當成查詢條件的一部分：

vulnerable query
SELECT * FROM users WHERE username = '<輸入>' AND password = '<輸入>'

靶機以 executescript() 執行查詢，代表它允許一次執行多條以分號 ; 分隔的 SQL。因此攻擊者不只能繞過登入，還能接著執行 INSERT、UPDATE、DELETE。登入成功後首頁會列出整個資料庫表格，方便在操作時觀察資料變化。

靶機資訊
內建帳號admin / 123456（管理員）、pony / password（一般使用者）
資料還原資料庫被改壞時，開啟 /reset-db 還原成初始兩個帳號

操作步驟

  1. 繞過登入。帳號欄位輸入下列字串，密碼隨意。OR 1=1 使條件永遠成立，-- 將其後的密碼檢查註解掉，因此不需正確密碼即可登入。注意 -- 後面要保留一個空格。
    username 欄位
    Admin' OR 1=1 --
  2. 觀察權限差異。登入後以 admin 介面新增一個不具管理權限的使用者，登出後改用新帳號登入，確認它無法進入 admin 頁面。
  3. 注入提權。在帳號欄位貼入下列字串，將指定使用者升級為管理員。
    提權 payload
    '; UPDATE users SET isAdmin=1 WHERE username='pony'; --
  4. 注入刪除資料。以同樣方式刪除指定使用者，回到首頁即可看到資料表的變化。
    刪除 payload
    hacker'; DELETE FROM users WHERE username='pony'; --

防禦修補

根本做法是採用參數化查詢（prepared statement），把使用者輸入當成純資料綁定，而非以字串拼接組成 SQL。靶機中 admin 新增使用者那段即為正確寫法，可作對照。

正確寫法
cursor.execute(
    "INSERT INTO users (username, password, isAdmin) VALUES (?, ?, ?)",
    (username, password, is_admin),
)
