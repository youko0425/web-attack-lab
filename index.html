// WEB ATTACK LAB

以攻代守 Web 攻防實戰

本站整理 ESAM「AI 資安進駐 Web 攻防」課程的三組靶機。每一頁說明漏洞成因、靶機環境、現場操作步驟，並附上可直接複製的攻擊 payload 與修補寫法，供學員在課堂上同步演練。

Core Concept

三個 Lab 指向同一個根本問題：「資料」與「程式碼」沒有分離。使用者的輸入被伺服器當成程式碼執行。SQLi 讓輸入被當成 SQL 指令，XSS 讓輸入在他人瀏覽器被當成 JavaScript，SSTI 讓輸入被當成模板語法，最終在伺服器上執行系統指令。

選擇你的 Lab

選擇實驗直接進入。每個 Lab 的指令與 payload 皆可一鍵複製，照頁面步驟即可完成演練。

Lab 01
SQL Injection
輸入被拼進 SQL 查詢字串，繞過登入並竄改資料庫。
High   PORT 5000
 Lab 02
XSS + Session Hijacking
惡意留言在受害者瀏覽器執行，竊取 cookie 並冒用身分。
High   PORT 5001 / 4444
 Lab 03
SSTI to RCE
輸入被模板引擎解析，由注入語法升級為遠端指令執行。
High   PORT 5002

使用方式

How to use 每個 Lab 頁面的指令區塊右上角都有 COPY 按鈕，點一下即可複製整段，直接貼到瀏覽器網址列、輸入框或終端機。靶機網址（trycloudflare）每次開課重新產生，上課時由講師現場公告，請把頁面範例中的 <靶機網址> 換成當天的實際網址。
使用規範 本站所有技術僅供課堂授權環境內的攻防演練。請勿對未授權之系統進行測試。課堂操作時不要執行破壞性指令（例如刪除資料、更改密碼），以免影響其他學員。
